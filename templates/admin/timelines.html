How It Works
Data Isolation

Each timeline contains completely separate data. Students, subjects, schedules, and grades in one year don't affect other years.

User Assignment

Each user can be assigned to a specific year. They will only see and manage data from their assigned year.

Year Switching

Admin users can switch between years using the dropdown in the navigation bar to view or manage different timelines.
