Excel File Format:

Your Excel file should have the following columns in order:

  1. Name - Student's full name (Required)
  2. Email - Student's email address (Required, must be unique)
  3. Phone - Phone number (Optional)
  4. Academic Year - 1, 2, 3, or 4 (Required)
  5. Section - A single letter A-Z (Required)
Note: Student IDs will be auto-generated. The first row should contain column headers.
